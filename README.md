# PayGoodBot — полностью рабочий каркас

Telegram-бот: меню, тарифы, баланс, пополнение, выпуск виртуальной карты.
Прямо сейчас всё работает "на моках" — без единого реального API — так что
можно сразу тестировать весь сценарий целиком.

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="твой_токен_от_BotFather"
python bot.py
```

По умолчанию `CARD_PROVIDER=mock` и `PAYMENT_PROVIDER=mock` — бот выдаёт
"игрушечные" карты и мгновенно подтверждает любое пополнение. Этого
достаточно, чтобы проверить весь путь пользователя: меню → тариф →
оплата → выпуск карты → список карт.

## Как устроено (чтобы потом было легко менять API)

```
bot.py                     — точка входа
config.py                  — тарифы, токен, выбор провайдера (env-переменные)
handlers/main.py           — вся логика бота (кнопки, сценарии)
handlers/keyboards.py      — инлайн-клавиатуры
services/card_provider.py  — ЗДЕСЬ подключается выпуск карт
services/payment_provider.py — ЗДЕСЬ подключается приём денег (эквайринг/СБП)
db/database.py             — SQLite: пользователи, карты, транзакции
```

Хендлеры бота никогда не вызывают Stripe/Lithic/эквайринг напрямую — они
вызывают `get_card_provider()` и `get_payment_provider()`, а те уже решают,
мок это или настоящий провайдер. Значит, чтобы подключить реальный API,
не нужно трогать сценарии бота вообще.

## Как подключить настоящий выпуск карт

1. Зарегистрируйся у провайдера (Stripe Issuing, Lithic, Marqeta — смотри,
   какие страны/валюты они поддерживают для твоего бизнеса).
2. В `services/card_provider.py` допиши метод `issue_card()` в классе
   `StripeIssuingProvider` (или `LithicProvider`) — вызов их API вместо
   `raise NotImplementedError`.
3. В `.env` / переменных окружения поставь `CARD_PROVIDER=stripe` и
   `STRIPE_SECRET_KEY=...`.

Всё, бот сразу начнёт выдавать настоящие карты — ни один хендлер менять
не нужно.

## Как подключить приём денег (СБП/эквайринг)

Та же логика: допиши `SBPProvider` в `services/payment_provider.py` под
API выбранного эквайера (ЮKassa, CloudPayments, Т-Банк и т.д.), поставь
`PAYMENT_PROVIDER=sbp` и ключ в переменных окружения.

## Деплой на Railway

Как и с твоим ride-ботом: подключаешь репозиторий, задаёшь переменные
окружения (`BOT_TOKEN`, при необходимости `CARD_PROVIDER`,
`PAYMENT_PROVIDER` и ключи), команда запуска — `python bot.py`.
